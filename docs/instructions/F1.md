1. git fetch 后 git merge origin/main。确认 main 已包含 T11b 与 lane-c 的全部改动（Dockerfile 中有 MALLOC_MMAP_THRESHOLD_ 与 MALLOC_TRIM_THRESHOLD_ 两个环境变量），此时本工作目录的代码应与 main 完全一致（git diff origin/main 为空）。不一致时停下来告诉用户

## 实验（全部用 tools/experiments.py，容器 --memory=256m --memory-swap=256m，真实内存读数，服务固定单核）

按顺序，每个场景结束后立即把 summarize.py 的输出存到 results/final/ 下：
1. S1 吞吐爬坡（不压缩）：最大可持续吞吐
2. S2 混合负载（S1 最大可持续吞吐的 70%）：默认 topk、回放 topk、stats 的 p50/p95/p99
3. S3 精度（长尾，每秒 3 万条，5 分钟）：召回、计数相对误差、落界率、去重用户数误差、p95 误差
4. S4 攻击流量（全随机，每秒 3 万条，10 分钟）：工作集每分钟峰值、降级级别、接受率
5. S5 过载与恢复：降级的进入、退出与恢复时间

如果时间紧张，按 S3、S4、S1、S2、S5 的优先级取舍，并在汇报中说明哪些没跑。
